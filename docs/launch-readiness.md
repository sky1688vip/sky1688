## 上线前管理员操作

| 顺序 | 操作 | 说明 |
|---|---|---|
| 1 | 使用 Manus 登录后台 | 项目所有者会自动获得 `admin` 角色；其他账号需由项目所有者在数据库中授予管理员角色。 |
| 2 | 创建 Dream1000 分类 | 分类会显示在公开筛选器中。 |
| 3 | 新建真实的 2D/3D 结果与 Dream1000 条目 | 先以草稿保存，再校对标题、号码、日期、释义与来源。 |
| 4 | 发布经核对的内容 | 仅 `published` 状态会被公开 API 和前台读取。 |
| 5 | 检查公开详情页 | 确认时间、号码、搜索结果和空状态表现符合运营要求。 |
| 6 | 创建项目检查点后发布 | 在管理界面点击 Publish 完成托管发布与域名配置。 |

## 运营边界

该项目未写入任何虚构结果、Dream1000 内容、用户评论或交易数据。当前公开端为空状态是预期行为；管理员完成真实内容录入和发布后，公开页面会自动显示。
