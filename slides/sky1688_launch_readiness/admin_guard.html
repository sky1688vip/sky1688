ACCESS CONTROL
后台写入由双层权限保护
05 / 09

前端负责清晰引导；服务端负责最终拒绝。任何写入都不能仅依赖界面隐藏。

01 / IDENTITY

Manus 登录

未登录访问后台时，只呈现登录保护界面，不展示内容管理能力。

SESSION REQUIRED
02 / ROLE

管理员角色

登录身份必须具备 admin 角色；非管理员获得明确的无权限提示。

ROLE CHECK
03 / SERVER

adminProcedure 校验

服务端对新增、编辑、发布和下架请求再次进行角色验证，未授权请求被拒绝。

FORBIDDEN IF DENIED
04 / RELEASE

发布状态控制

内容先保存草稿，审核后发布；公开 API 只返回已发布条目。

PUBLISHED ONLY
SERVER-SIDE GUARANTEE

即使用户绕开界面直接调用接口，管理员路由仍会在服务端基于用户角色进行拒绝。前端权限提示与后端权限控制共同构成完整边界。
